# Komentář k zákonu č. 428/2012 Sb., o majetkovém vyrovnání s církvemi a náboženskými společnostmi a o změně některých zákonů (zákon o majetkovém vyrovnání s církvemi a náboženskými společnostmi)

Otevřený komentář k zákonu o majetkovém vyrovnání s církvemi a náboženskými společnostmi — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; preambule, oprávněné a povinné osoby, vydávání věcí a výluky, postup při vydání, omezení převodu, finanční náhrada, smlouva o vypořádání a příspěvek na podporu činnosti.

Konsolidované znění: dokument e-Sbírky `SB-2012-00428_2020-01-01`.
